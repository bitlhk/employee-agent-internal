# 贷后风控岗位助手 1.2.1 发布记录

## 发布结论

`post-loan-risk-control-assistant@1.2.1` 已完成本地正式发布。该版本不新增平台治理层，主要提升贷后风控专业编排：

- 全景核查优先使用统一风险快照，避免逐域重复取数；
- 聚合最不利风险信号后单次执行确定性预警；
- 从指标罗列升级为第一、第二还款来源和风险传导分析；
- 人工复核动作按 P0 / P1 / P2 和时间要求排序；
- 深度 A2A 分析改为显式增强，不阻断快速核查和预警。

## 版本对照

评测环境固定为同一 GLM-5.2、同一风控岗位和同一套 MCP 工具，仅替换 Skill Artifact。
