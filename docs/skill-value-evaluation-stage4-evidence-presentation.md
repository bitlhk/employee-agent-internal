# Skill 价值评测第四阶段：价值证据呈现

验证时间：2026-09-04

## 阶段目标

前三阶段已经完成评测稳定性、重点 Skill 适配验证，以及由负向结果牵引
`goldencoach-stage-evaluation@2.2.1` 改进并发布。第四阶段不增加发布门禁，
而是把真实 A/B 结果整理成业务人员能直接理解、管理者能复核和导出的证据。

## 用户可见结果

每次完成真实 A/B 后，结果页统一呈现：

- 对比类型：有无 Skill、Skill 版本、模型或综合配置对比；
- 较优配置和逐题胜负；
- 专业匹配、业务完整、表达清晰、可执行性四维平均分及 B-A 差值；
- 左右执行成功率、有效 Judge 数、高置信结论数和平均耗时；
- 同题同环境、匿名 Judge、Finance Skill Eval 与 Promptfoo 版本；
- 配置指纹和报告指纹。

历史结果使用同一套摘要，不再只是保存左右长答案。用户可以导出 Markdown
证据报告，报告包含完整配置、题目、左右输出、逐题 Judge 结论、四维评分、
评审依据、资产版本及指纹。

## 可信边界

- 结果来自当前环境真实执行，不使用静态演示数字替代运行结果；
- 新评测记录保存 Skill 版本 ID 与 Artifact SHA-256，历史格式缺少的字段明确留空；
- 导出的报告证明指定模型、Skill 资产、题目和运行环境下的本轮结果，不扩大为
  对所有任务和生产场景的普遍保证；
- AI Judge 仍标记为匿名业务 Judge，不冒充独立人类专家 Ground Truth；
- 本阶段没有改变组题、Runtime 执行、工具装配、Judge 或 Skill 发布逻辑。

## 通用性

证据汇总只依赖标准评测任务合同，不包含财富、保险、投研、审计、风控或陪练的
业务硬编码。任何能够进入 EA Skill 价值评测的 Skill，都使用同一个结果摘要和
导出格式。

## 演示路径

```text
技能市场
→ 打开任一 Skill
→ 点击“评测”
→ A/B 选择模型和 Skill 版本
→ 准备测试并开始对比
→ 实时查看两侧输出
→ 查看“价值证据摘要”
→ 切换“历史结果”复核正式任务
→ 点击“导出证据”获得完整报告
```
