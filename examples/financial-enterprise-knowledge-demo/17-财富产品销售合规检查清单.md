# 财富产品销售合规检查清单（演示）

> 文件编号：LG-WM-CHK-001
> 版本：V1.0
> 归口部门：合规管理部（演示）
> 生效日期：2026-08-01
> 密级：内部

## 1. 适用范围

用于财富经理在生成正式产品推荐、客户沟通材料或发起销售相关动作前进行复核。该清单是作业检查工具，不代替系统确定性 Policy。

## 2. 前置条件

已获得授权客户的当前画像和目标产品事实；当前适当性制度有效；涉及写入或外发时，相应业务能力和确认流程可用。

## 3. 操作步骤

1. 核对客户与产品数据来源和时间；
2. 完成 A 至 E 五组检查；
3. 对未通过项记录原因；
4. 命中硬性禁止项时停止操作；
5. 通过后保存检查结果并进入后续确认或执行。

## 4. 必查项清单

### A. 客户与权限

- [ ] 客户属于当前用户授权范围
- [ ] 客户身份、联系方式及关键声明来源可核验
- [ ] 当前任务只使用最小必要客户字段

### B. 风险与需求

- [ ] 风险测评有效
- [ ] 投资期限、流动性和损失承受能力已确认
- [ ] 客户明确需求与推荐目标一致

### C. 产品与渠道

- [ ] 产品当前在售
- [ ] 产品风险等级符合要求
- [ ] 本机构、本组织和当前渠道可销售
- [ ] 最低金额、期限和开放安排匹配

### D. 表达与披露

- [ ] 未承诺本金或收益
- [ ] 已说明主要风险和不利情景
- [ ] 历史业绩已标注期间、来源和非预测属性
- [ ] 推荐理由包含客户侧和产品侧依据

### E. 动作与留痕

- [ ] 对外发送已使用批准通道
- [ ] 需要确认的动作已获得确认
- [ ] 写操作具有幂等键或业务防重机制
- [ ] 执行依据可追溯到制度与数据版本

## 5. 禁止项

任一以下情况出现时不得继续正式推荐：客户归属失败、风险测评失效、产品风险错配、产品停售或渠道不可用、当前制度无有效版本、治理策略不可用。

## 6. 异常处理与升级

检查项缺失时应向用户说明需要补充的业务信息；系统依赖不可用时应说明可否稍后重试。涉及例外销售、投诉、重大客户损失或疑似违规时升级合规管理部门。

## 7. 会后留痕

保存检查完成时间、执行人、未通过项、处置结果和关联业务记录。不得以“已口头确认”替代系统要求的确认与留痕。
