- [《理财公司理财产品销售管理暂行办法》](https://www.nfra.gov.cn/cn/view/pages/rulesDetail.html?docId=986408&itemId=4214)：不得误导投资者购买与风险承受能力不匹配的产品，不得夸大或承诺收益，并应持续评估风险承受能力。
