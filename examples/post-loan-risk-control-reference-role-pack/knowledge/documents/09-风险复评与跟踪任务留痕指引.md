# 风险复评与跟踪任务留痕指引

**版本：V1.0**
**责任部门：贷后管理部、运营管理部（演示）**

## 1. 适用场景

- 预警等级为 YELLOW、ORANGE 或 RED；
- 关键数据缺失，需要补充材料；
- 风险事件需要持续核验；
- 人工复核决定安排再次检查。

## 2. 任务最小字段

```text
企业脱敏标识
跟踪目标
到期时间
优先级
来源风险事件
责任人/责任岗位
幂等键
```

## 3. 操作要求

1. Agent 先生成任务草稿；
2. 向用户展示目标、时间、优先级和所需材料；
3. 用户明确确认后才能写入；
4. 写入必须绑定幂等键；
5. 返回业务任务 ID 和状态；
6. 失败时保留可安全重试的回执，不重复创建。

## 4. 禁止事项

不得自动向客户发送风险信息，不得把内部预警结论写入无授权系统，不得通过修改跟踪任务绕过正式风险处置审批。
