# 完整训练评估

仅当用户明确要求完整复盘、正式评分、总分或等级时读取本文件。

## 七个能力模块

| 模块 | 默认满分 | 主要观察点 |
| --- | ---: | --- |
| 约访 | 5 | 身份与联系目的、价值钩子、时间许可 |
| 寒暄 | 5 | 状态确认、自然承接、沟通节奏 |
| 事实发现 | 15 | 开放提问、场景与需求、现有安排、约束 |
| 产服讲解 | 15 | 产品事实、需求匹配、比较依据、表达准确性 |
| 价值塑造 | 10 | 客户可感知价值、方案取舍、场景化解释 |
| 异议处理 | 40 | 对实际出现的异议使用 LSCPA；最多四个异议 |
| 成交与推进 | 10 | 时机、选择权、下一步、责任与时间 |

默认分值用于完整训练评估，不代表监管统一标准。用户或机构提供正式评分体系时，以其体系为准，并注明版本。

## 评分方法

1. 每项得分必须对应可引用的顾问原句或对话动作。
2. 对话未覆盖的模块标记“未涉及”，同时单列全流程完整度；不得把未观察到等同于能力为零。
3. 无法从文字记录观察的行为标记“证据不足”，例如未带时间戳时不能判断停顿秒数。
4. 只有在分母和折算方法明确时才输出总分；否则输出模块表现和完整度，不制造精确分数。
5. 任何等级都必须同时说明适用的评分口径。

## 完整评估顺序

1. 全局诊断：覆盖阶段、主要优势、首要断点、红线事实。
2. 客户事实摘要：仅复述客户明确表达的情况和诉求。
3. 模块评估：证据、评价、改进话术。
4. 异议分析：只分析实际出现的异议。
5. 评分与完整度：分别呈现，不混为一个分数。
6. 下一轮训练：最多三个按优先级排序的动作。
