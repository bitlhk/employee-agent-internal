# 金融机构运营制度演示库

> 版本：2026.07-demo.1
> 性质：完全虚构的产品演示资料，不代表任何真实企业制度，也不构成法律、投资或合规意见。

这套资料用于验证岗位智能体对企业内部制度的检索、跨文档归纳和来源引用能力。制度结构参考公开法律法规和监管材料，住宿金额、审批层级、时限、系统名称及内部分级均为演示口径。

## 内容范围

1. 差旅与费用报销管理办法
2. 差旅住宿与交通标准表
3. 电子发票与报销附件指引
4. 财富客户适当性与产品销售指引
5. 反洗钱客户尽职调查操作指引
6. 客户信息保护与数据外发规范
7. 贷后风险预警与升级处置
8. 债券报价与投资研究合规规范
9. 员工利益冲突与证券投资申报
10. 审批职责与内部服务目录

## 建议测试问题

- 普通员工去上海出差三晚，酒店每晚上限是多少？
- 临时买了公务机票但没有事前审批，还能报销吗？
- 电子发票打印后，原始电子文件还需要保留吗？
- C2 客户能否购买 R4 产品？客户坚持购买怎么办？
- 客户身份证照片能否发到个人邮箱，让供应商代为处理？
- 客户交易行为异常时，能否告诉客户已经提交可疑交易报告？
- 贷款客户连续两期现金流下降，应该触发什么级别的预警？
- 群聊中的债券报价可以直接转发给客户吗？
- 员工买入限制名单证券前需要做什么？

回答应同时区分“公开监管原则”和“本演示库内部规则”，并显示实际引用文件。
