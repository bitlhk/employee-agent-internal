# 智能审核岗位助手 1.1.0 发布记录

## 发布结论

`smart-audit-assistant@1.1.0` 面向审核专员岗位默认预装发布。本次不增加审核治理引擎，重点提高审核人员可直接采用的专业判断：

- 将案件材料转换为“材料、字段、主体、期间、口径、确认状态”证据矩阵；
- 比较金额前先对齐主体、期间和收入/流水等统计口径；
- 明确计算绝对差额与相对差异，并显示分母，不临时发明风险阈值；
- 将问题区分为已核验冲突、口径不可比、证据不足和待人工判断；
- 补件只围绕当前未解问题，说明“补什么、证明什么、补齐后重跑哪项审核”；
- 材料齐备时能够形成简洁工作意见，不为了显得审慎而制造阻断。

EA Runtime 继续负责岗位授权、当前规则资格、人工复核边界和写操作确认；本 Skill 负责证据组织、一致性判断、影响解释和审核沟通。

## 同模型对照

评测固定为 GLM-5.2、审核专员岗位和同一组平台审核工具，只替换 Skill Artifact。

| 任务 | 1.0.0 | 1.1.0 |
|---|---|---|
| 收入与流水期间不一致 | 容易套用通用材料清单并把不可比差异升级为 L4 | 输出 45 万元、占申报值 56.25%，判定为口径不可比，人工复核参数为 L1 |
| 贷款金额与用途合同差异 | 能识别金额缺口，但补件和审核影响较分散 | 输出 50 万元、占申请金额 10%，定位为用途证据缺口，只补差额用途证明 |
| 材料齐备正向意见 | 倾向增加未触发的复核事项 | 材料、主体、期间和用途一致时形成可直接采用的工作意见 |
| 材料标签差异 | 可能按字符串差异制造缺件 | 将明确同义材料标签归一后再判断完整性 |

匿名业务 Judge 在最终收入差异回归中高置信度选择 1.1.0；用途差额和正向意见由同模型真实 Runtime 对照及人工业务复核共同确认。Judge 是 GLM-5.2 匿名业务评审，不表述为独立人类信贷审核专家签署。

## 验证口径

- 真实 EA Runtime 装配并验证 Skill 版本身份；
- 左右侧使用同一模型、同一岗位和同一工具环境；
- Promptfoo 负责批次执行与输出采集；
- 专业质量按专业匹配、业务完整性、表达清晰度和可执行性比较；
- Role Pack 合同、受控场景、定向测试和 Artifact SHA-256 在发布时重新计算。

## 演示重点

使用“申报月均收入 80 万、流水月均入账 35 万、期间不完全重合”的案例。旧版容易先补一套通用材料并把疑点升级；新版先说明两者为什么不可直接比较，再量化 45 万元差额和 56.25% 相对差异，给出最少的期间对齐与流水分类证据，让审核人员能继续工作而不是只得到一个阻断结论。
