# 车险产品讲解与销售考点使用指引（演示）

> 文件编号：LG-IA-GDE-001
> 版本：V1.0
> 归口部门：车险产品部、培训发展部（演示）
> 生效日期：2026-08-11
> 密级：内部

## 1. 目的

规范保险顾问使用产品详情、Wiki 模块、话术模块和销售考点进行产品解释、产品对比和销售训练。考点用于指导沟通和评价，不替代正式条款、报价或承保规则。

## 2. 数据来源

产品名称、类别、定位、目标人群、保障责任、限制、话术和考点必须来自 `insurance_product_exam_points` MCP。本指引只规定使用方式，不维护固定产品事实。

## 3. 产品讲解步骤

1. 查询并确认产品；
2. 读取完整产品详情；
3. 明确产品定位和适用场景；
4. 解释主要保障和限制；
5. 结合客户事实说明相关性；
6. 披露待核实事项和正式信息入口；
7. 不确定时转人工或正式系统。

## 4. 产品对比维度

比较多个产品时使用一致维度：

- 产品定位；
- 适用车辆和使用性质；
- 主要保障；
- 主要限制和免责；
- 新能源、营运或驾乘场景覆盖；
- 服务和增值内容；
- 需要正式系统确认的字段。

不得只比较有利卖点，隐藏限制或用不同口径制造优劣结论。

## 5. 考点使用

产品考点可按约访、寒暄、事实发现、产服讲解、异议处理和成交阶段调用。使用时：

- 只选择与当前阶段相关的考点；
- 说明证据来自客户对话还是产品资料；
- 将 `must_cover` 类考点列为必讲项；
- 将示例话术作为参考，不要求员工逐字照读；
- 评分时不把未出现阶段虚构为已完成。

## 6. 必查项

- [ ] 产品来自 MCP 当前结果
- [ ] 产品详情和版本可定位
- [ ] 限制与免责未被省略
- [ ] 考点与当前产品及阶段一致
- [ ] 没有编造报价和优惠
- [ ] 没有承诺承保和赔付
- [ ] 示例产品已明确演示属性

## 7. 禁止表达

- “肯定能赔”“什么情况都赔”；
- “一定是全网最低价”；
- “不用如实告知也没关系”；
- “系统已经确认承保”；
- “这个示范产品现在就可以买”；
- 以考点或内部话术替代正式条款。

## 8. 异常处理

产品详情不可用时只提供产品摘要并提示核实；考点与详情冲突时停止使用冲突内容并联系产品责任部门；客户提出正式投保、报价、核保或理赔问题时进入对应业务渠道。
