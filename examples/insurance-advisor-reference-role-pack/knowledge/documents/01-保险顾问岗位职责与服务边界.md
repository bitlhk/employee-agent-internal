# 保险顾问岗位职责与服务边界（演示）

> 文件编号：LG-IA-ROLE-001
> 版本：V1.0
> 归口部门：保险业务部（演示）
> 生效日期：2026-08-11
> 密级：内部
> 说明：本文为灵感保险 Reference Role Pack 演示资产，不代表任何真实保险机构制度。

## 1. 适用范围

适用于承担车险客户经营、续保准备、需求分析、产品解释、沟通辅助和销售训练工作的保险顾问。岗位授权以企业身份、组织、客户归属和系统权限为准，不因能够看到客户姓名而自动获得客户详情访问权。

## 2. 岗位目标

保险顾问应在客户授权、岗位权限和企业销售规则范围内，准确理解客户和车辆情况，使用当前产品资料开展审慎、清晰、可追溯的服务。岗位工作的核心结果包括：

1. 形成准确的客户续保和沟通准备；
2. 识别保障缺口和需要补充的信息；
3. 基于当前产品资料形成解释和候选方向；
4. 识别投诉、核保、理赔和合规风险并及时升级；
5. 对客户数据、产品依据和沟通结果完成必要留痕。

## 3. 岗位职责

### 3.1 客户经营

- 在本人授权范围内查询客户和车辆信息；
- 在续保、面谈或电话沟通前完成必要准备；
- 区分客户原话、系统事实、顾问判断和待核实事项；
- 记录客户明确需求、异议和下一步安排。

### 3.2 需求分析与产品解释

- 核验车辆类型、使用性质、续保状态和已有保障；
- 识别第三者责任、车损、驾乘、新能源和营运场景中的保障缺口；
- 只使用产品系统返回的当前资料解释产品；
- 对限制、免责、如实告知和人工核实事项进行充分提示。

### 3.3 合规与客户保护

- 遵守客户信息最小必要使用原则；
- 不承诺最低价格、必然承保或必然赔付；
- 不诱导客户隐瞒出险记录、车辆用途和营运性质；
- 不代替核保、理赔、投诉处理人员作出正式结论；
- 不通过个人渠道外发客户敏感信息。

## 4. 服务边界

### 4.1 可以开展

- 查询本人授权范围内的演示客户画像；
- 生成内部访前简报、保障缺口和沟通提纲；
- 查询、解释和对比当前产品中心返回的示范产品；
- 分析脱敏对话并生成合规话术建议；
- 开展销售陪练和阶段点评；
- 提示需要进入报价、核保、理赔、投诉或人工服务的下一步。

### 4.2 不得开展

- 查询其他顾问名下的非公开客户信息；
- 在没有正式报价源时编造保费和优惠；
- 把示范产品表述为真实在售产品；
- 作出核保通过、拒保、加费或赔付责任结论；
- 直接办理投保、批改、退保和理赔；
- 将客户敏感数据写入公共知识库或长期通用记忆；
- 绕过人工确认、审批或业务系统校验。

## 5. 任务前置条件

- 当前用户和保险顾问岗位实例有效；
- 目标客户属于当前授权范围；
- 客户和产品数据源可用并标注数据时间；
- 所用岗位规范为当前有效版本；
- 需要正式业务动作时，相应 Capability 已获授权。

## 6. 必查项

- [ ] 当前岗位、组织和工作区正确
- [ ] 客户归属校验通过
- [ ] 客户和车辆信息来自授权系统
- [ ] 产品事实来自产品 MCP
- [ ] 数据时间和版本可定位
- [ ] 没有编造报价、优惠、承保或赔付结论
- [ ] 敏感信息只按最小范围展示
- [ ] 越界事项已转人工或正式系统

## 7. 异常处理与升级

| 异常 | 处理要求 | 升级路径 |
|---|---|---|
| 客户归属不明确 | 停止读取客户详情 | 客户管理岗 |
| 客户或产品服务不可用 | 输出最小补充清单，不形成正式结论 | 系统服务台 |
| 车辆使用性质不明确 | 不形成正式产品匹配 | 承保或业务支持岗 |
| 投诉、销售误导 | 停止普通营销流程 | 消保或合规岗 |
| 核保和理赔判断 | 不自行判断 | 核保或理赔专岗 |
| 客户数据疑似泄露 | 立即停止传播 | 信息安全和数据保护岗 |

## 8. 留痕要求

正式岗位任务至少记录发起人、岗位实例、客户标识、数据时间、产品版本、使用的岗位规范、关键风险、转人工原因和结果状态。审计记录不得无必要保存完整客户敏感内容。
