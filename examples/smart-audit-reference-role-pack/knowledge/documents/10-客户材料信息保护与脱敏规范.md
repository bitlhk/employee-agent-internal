# 客户材料信息保护与脱敏规范

**版本：V1.0**
**责任部门：数据管理部、信息安全部（演示）**

## 1. 适用信息

- 身份证件、联系方式、住址和生物特征；
- 银行账号、交易流水、收入和资产负债；
- 企业证照、合同、发票、订单和经营数据；
- 授信申请、审核意见、疑点和审批记录；
- 影像、OCR 文本、模型提取结果和任务附件。

## 2. 最小必要原则

只向 Agent 提供当前任务需要的材料和字段。任务只需核对账户一致性时，优先提供受控标准化值或后四位，不提供完整账号。

## 3. 展示脱敏

| 信息 | 默认展示 |
|---|---|
| 身份证件号 | 前三位和后四位，其余隐藏 |
| 银行账号 | 仅后四位 |
| 手机号 | 前三位和后四位 |
| 地址 | 保留到审核所需层级 |
| 企业统一代码 | 内部审核可按权限展示；对外摘要脱敏 |
| 交易对手 | 按任务必要性展示名称或安全摘要 |

脱敏只用于展示，字段一致性比较应在受控服务端执行。

## 4. 模型和外发

- 未获得企业允许时，受限材料不得发送到外部模型或第三方 MCP；
- 模型上下文只包含业务推理需要的信息；
- Context Receipt、指纹和交互 Grant 不进入模型可见文本；
- 不在 Prompt、日志或错误消息中写入密钥、会话凭证或完整敏感字段；
- 上游错误对用户返回通用说明和 request ID。

## 5. 存储与删除

- 原始材料存储在受控文件或案件系统；
- Knowledge 不保存动态客户材料；
- 任务结束后按企业保留策略处理临时文件；
- 用户撤回或合规删除时，按记录类型执行删除或不可逆匿名化；
- Audit 仅保留证明所需的引用、哈希和动作，不复制完整材料。

## 6. 安全披露

因岗位、密级或案件范围被过滤的材料，不向用户展示名称和精确数量。仅说明“存在无权访问内容，未纳入本次审核”。

## 7. 违规处理

发现跨客户材料、未授权下载、异常批量访问或敏感信息外发时，立即停止任务，记录安全事件并通知有权管理员。
