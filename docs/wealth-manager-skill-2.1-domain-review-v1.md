## 四个核心案例

### `WM-PRE-001` 产品到期与流动性冲突

确认重点：不能从“续哪款产品”开始；必须先核实资金用途、时间和来源，避免混同企业经营资金与家庭投资资金。专业价值在于识别流动性、期限和收益诉求之间的冲突。

### `WM-PRE-004` 大额流动性事件与风险意愿

确认重点：风险等级只提供适当性边界，不能替代客户对具体金额回撤的真实感受。应区分风险承受能力、风险意愿和投资经验，并避免一次性高仓位配置。

### `WM-COM-008` 亏损客户关系修复

确认重点：先基于历史记录复盘市场损失、销售沟通和持续服务，不用新产品覆盖旧问题，不以“回本”作为唯一决策标准，也不在事实不足时自行认定法律责任或正式投诉。

### `WM-REC-009` 条件满足后的正式推荐

确认重点：先形成客户目标、流动性底线、期限与风险约束，再从 `eligibleProducts` 映射产品；必须解释匹配、风险、费用、期限和排除项。`323` 天期限产品不得描述为高流动性资产。A/B 方案只在确有比较价值时生成，不为格式强制输出。

## 专业质量判定

候选 Skill 已具备以下可评测能力：

1. 区分已知事实、待验证假设、缺失信息和冲突信息；
2. 从客户表面诉求识别影响决策的核心矛盾；
3. 首轮提出不超过三个高信息增益问题；
4. 按目标、流动性、期限、风险意愿和持仓形成组合约束；
5. 坚持先组合、后产品，并解释正式候选与排除项；
6. 把专业判断转成财富经理可直接采用、但仍需人工确认的沟通；
7. 在客户或产品事实不足时保留可支持的分析，不编造完整建议。
