# 企业贷后全景核查作业指导书

**版本：V1.0**
**责任部门：贷后管理部（演示）**

## 1. 前置条件

- 已确认当前用户、岗位和企业归属；
- 已取得企业统一标识；
- 数据来源处于可用状态；
- 本次核查目的和基准日期明确。

## 2. 必查数据域

| 数据域 | 必查项 | 来源要求 |
|---|---|---|
| 企业画像 | 名称、统一信用代码、行业、规模、经营状态 | 企业主数据 |
| 贷款账户 | 余额、期限、利率、五级分类、逾期天数 | 信贷核心系统 |
| 信用评级 | 当前等级、上次等级、评级日期 | 评级系统 |
| 还款表现 | 近 24 个月逾期次数和最长逾期 | 还款系统 |
| 财务 | 近三年收入、利润、现金流、负债 | 财务报表系统 |
| 债项保障 | 押品和担保概况 | 押品/担保系统 |

## 3. 操作步骤

1. 先调用企业画像，核对企业主体；
2. 再查询贷款账户和信用评级；
3. 并行获取财务、还款、押品和担保数据；
4. 为每个数据域记录来源和 `asOf`；
5. 列出缺失字段，不得静默填充；
6. 输出事实概览，不在本步骤直接给出综合风险等级。

## 4. 降级处理

企业主体或贷款账户无法核验时停止任务。财务、押品或外部信息部分缺失时，可输出已核验事实和补充清单，但结果标记为“有限可用”。

## 5. 留痕

记录查询企业标识的哈希、数据系统、数据时间、失败数据域和下一步补充责任人，不在收据中复制完整敏感原文。
