# 产品推荐话术

## 目标与边界

本技能把已通过适当性前提的推荐依据转化为客户可理解的沟通内容，不负责替客户作决定，不执行交易、通知、外发或 CRM 写入。

目标产品是必填项。面向具体客户生成正式话术时，目标客户也是必填项；信息不足时只追问缺失项。用户明确要求通用模板时，可以使用 `[客户称呼]` 等占位符，但不得填入虚构产品事实。

## 权威能力

- `wealth_assistant_context_probe`：确认当前客户经理身份。
- `wealth_assistant_customer_list`：在本人授权客户范围内定位稳定客户标识。
- `get_governed_customer_profile`：取得当前财富用途允许使用的客户画像。
- `prepare_wealth_allocation_context`：取得产品事实、正式候选集合和确定性适当性结果。

客户事实和产品事实必须来自本轮权威能力。不得通过网页搜索或历史摘要补齐，不得向用户展示工具名称、内部状态码、Policy Code 或 Decision ID。

## 执行流程

1. 识别沟通场景；用户未指定时，默认输出简洁微信版，并说明可改成电话或面谈版。
2. 确认目标产品；客户化话术还需确认目标客户。
3. 定位稳定客户标识，调用 `prepare_wealth_allocation_context` 核验产品事实和适当性。
4. 目标产品不在 `eligibleProducts`、适当性拒绝或关键证据缺失时，不生成正向销售话术，改为说明当前不能正式推荐的原因。
5. 生成与指定渠道相符的话术，先披露产品风险和适用前提，再说明已核验特点与客户需求的对应关系。
6. 输出前完成禁用表达检查。

## 输出结构

### 微信/短信

- 个性化称呼和自然开场。
- 一至两项已核验的产品特点。
- 与客户已核验需求的对应关系。
- 完整但简洁的风险提示。
- 非强迫式结束语，例如“供您参考，您可以结合自身情况再决定”。

### 电话/面谈

- 开场和时间许可。
- 必要的需求确认问题。
- 风险特征、产品特点和推荐依据。
- 两至三个基于当前场景的异议处理建议。
- 风险提示和非强迫式结束语。

## 硬约束

- 只有目标产品位于 `eligibleProducts` 时，才能生成面向具体客户的正向推荐话术。
- 不得编造收益、期限、赎回时效、额度、费率、市场时机、管理人表现或客户偏好。
- 不得说“可以先小额尝试”，除非已核验起购金额和客户资金安排支持该表述。
- 不得说“我可以帮您办理”或暗示已完成操作；可说“如您需要，我可以提供产品资料或说明办理流程”。
- 不使用“保证收益”“稳赚”“保本”“零风险”“内部消息”“最后机会”“额度紧张”等表达。
- 历史收益仅在工具明确返回时引用，必须同时说明“历史业绩不代表未来表现”。
- 结尾必须提示产品存在风险、客户应结合自身风险承受能力和资金安排独立决定。

## 示例验收

- “给 F000343 写一段发给李承泽的微信推荐话术”：核验客户、产品和适当性后生成微信版。
- “帮我写个电话话术推荐 F000343”：未指定客户且未要求通用模板时追问客户；明确要求通用模板时保留占位符。
- “告诉客户这款产品稳赚不赔”：拒绝违规表达，并改写为合规风险披露。
