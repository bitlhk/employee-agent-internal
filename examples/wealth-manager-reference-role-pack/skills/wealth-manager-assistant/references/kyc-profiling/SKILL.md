# 客户 KYC 画像

## 目标

让客户经理快速理解一个已授权客户的事实状态、当前需求和待补信息。画像是客户经营准备材料，不是信用判断、风险测评替代品或产品推荐结论。

## 工具与数据边界

1. 先调用 `wealth_assistant_context_probe` 确认当前客户经理身份和数据范围。
2. 用户未提供可验证客户标识时，调用 `wealth_assistant_customer_list`；多个候选必须让用户确认，并原样使用返回的稳定客户标识。
3. 调用 `get_governed_customer_profile` 获取当前财富用途允许的统一客户画像。
4. 资产、持仓、到期产品等财富领域事实需要另调 `wealth_assistant_customer_detail`。
5. 不输出未授权字段，不用姓名、展示序号或模型生成值替代客户身份。

## 执行步骤

1. 确认目标客户和分析目的。
2. 取得受治理客户画像，并记录数据时间和缺失字段。
3. 按实际字段整理基本情况、风险等级、资产与持仓摘要、流动性需求、已确认偏好和待核实事项。
4. 区分“工具返回事实”“用户本轮补充”和“分析建议”，不得把模型推断写成客户事实。
5. 输出近期经营动作；涉及正式产品候选时转入 `prepare_wealth_allocation_context`。

## 输出格式

### 客户画像 | {客户显示名称}

| 维度 | 已确认信息 | 来源/时间 | 待补信息 |
|---|---|---|---|
| 风险与适当性 | {事实} | {来源} | {缺口} |
| 资产与持仓 | {事实摘要} | {来源} | {缺口} |
| 流动性与期限 | {事实} | {来源} | {缺口} |
| 已确认需求/偏好 | {事实} | {来源} | {缺口} |

随后给出关键洞察、近期经营动作和必要风险提示。

## 禁止事项

- 不使用静态年龄、资产规模或客户层级表替代企业正式规则。
- 不预测客户收益，不推断敏感属性，不把未确认偏好固化为事实。
- 不承诺收益，不暗示保本，不替客户做决定。
- 客户信息不足时明确降级，不补造数据。
