# 电子发票与报销附件指引（演示）

## 1. 可接收的电子凭证

包括数电票、增值税电子发票、电子客票、航空运输电子客票行程单、铁路电子客票、银行电子回单和财政电子票据。来源合法、真实且满足归档条件的电子凭证可作为报销入账依据。

## 2. 提交要求

1. 应上传从开票平台、航司、铁路或供应商取得的原始电子文件，不能仅上传手机截图或聊天转发图片。
2. 报销单应记录票据号码、开票日期、销售方、含税金额、费用事项和对应申请单号。
3. 系统查验票据真实性并校验重复入账。查验失败、字段不完整或票面信息与业务不符时，由经办人补正。
4. 纸质打印件仅用于阅读或流转时，仍需保存原始电子凭证；不得以打印件替代电子文件归档。
5. 同一张票据不得在不同报销单、不同法人或不同成本中心重复提交。

## 3. 特殊情况

- 发票抬头或纳税人识别号错误：退回重开，不得手工涂改。
- 个人先行支付：需提供本人支付记录；超过 5000 元的非紧急采购原则上应使用公司付款流程。
- 发票金额大于报销金额：说明不可报销部分，系统记录本次核销金额，剩余部分不得再次报销，除非同一合同明确分摊。
- 境外票据：附中文说明、支付记录和报销日汇率依据，由税务岗复核。

## 4. 归档与保密

电子凭证应与审批、合同、验收和付款记录建立关联，保存在企业受控系统。包含客户姓名、账户、身份证件或交易信息的附件应按敏感数据管理，不得通过个人邮箱、个人网盘或公共文件传输服务流转。

## 5. 公开规则依据

财政部、国家档案局关于电子会计凭证的公开规则明确：电子凭证需合法真实、传输存储安全可靠、具备审签和防重复入账能力；如以纸质打印件报销，仍应保存对应电子凭证。本文件在此基础上增加了虚构企业的操作步骤。
