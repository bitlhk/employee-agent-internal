# 财富经理岗位职责与服务边界（演示）

> 文件编号：LG-WM-ROLE-001
> 版本：V1.0
> 归口部门：零售财富管理部（演示）
> 生效日期：2026-08-01
> 密级：内部
> 说明：本文为灵感银行 Reference Role Pack 演示资产，不代表任何真实机构制度。

## 1. 适用范围

适用于承担个人财富客户经营、需求分析、资产配置辅助、产品适配、客户回访和业务留痕工作的财富经理。实习、外包及临时支持人员应按实际授权范围执行，不因参与客户服务自动获得客户数据权限。

## 2. 岗位目标

财富经理应在客户授权、岗位权限和适当性要求范围内，为客户提供持续、审慎、可解释的财富管理服务。岗位工作的核心结果包括：

1. 形成准确、及时的客户经营判断；
2. 基于当前客户事实和现行制度提出适配建议；
3. 对关键业务动作完成确认、审批和留痕；
4. 及时识别风险、异常和需要升级处理的事项。

## 3. 岗位职责

### 3.1 客户经营

- 维护本人授权范围内客户的服务计划；
- 在拜访、回访和产品到期前完成必要准备；
- 记录客户明确表达的目标、期限、流动性需求和风险偏好；
- 对未决事项设置责任人和计划完成时间。

### 3.2 需求分析与配置辅助

- 核验客户身份、风险测评和数据时间；
- 分析资产结构、集中度、期限和流动性；
- 在当前可售产品范围内筛选适配候选；
- 清楚区分事实、客户陈述、分析判断和待核实事项。

### 3.3 合规与客户保护

- 执行客户信息最小必要使用原则；
- 在推荐、销售和外发材料前完成规定检查；
- 不规避风险测评、产品准入、渠道限制或人工确认；
- 发现疑似欺诈、洗钱、投诉或重大风险时按流程升级。

## 4. 服务边界

### 4.1 可以开展

- 查询本人被授权管理的客户信息；
- 生成内部访前简报、配置分析和沟通提纲；
- 查询当前在售且本岗位、本渠道可访问的产品；
- 创建草稿、待办和回访任务；
- 在获得必要确认后执行授权范围内的业务动作。

### 4.2 禁止项（不得开展）

- 查询或推断其他财富经理名下客户的非公开信息；
- 擅自修改客户风险等级、身份信息或交易记录；
- 将未经核验的模型输出作为正式制度、产品事实或客户事实；
- 承诺本金、收益或无风险；
- 通过私人邮箱、个人网盘或未经批准的通道外发客户资料；
- 将客户敏感数据写入公共知识库或长期通用记忆。

## 5. 前置条件

开展客户任务前应确认：

- 当前用户身份和财富经理岗位实例有效；
- 目标客户属于当前授权数据范围；
- 所需客户和产品数据源可用且标注数据时间；
- 所用制度处于生效状态并适用于当前岗位；
- 业务写入能力已授权，必要时具备人工确认和幂等保护。

## 6. 必查项清单

- [ ] 当前岗位、组织和工作区正确
- [ ] 客户归属与访问权限通过
- [ ] 风险测评状态和有效期已核验
- [ ] 客户数据与产品数据有明确时间
- [ ] 正式建议使用现行制度版本
- [ ] 高风险动作已进入确认或审批流程
- [ ] 结果保留必要执行依据

## 7. 异常处理与升级

| 异常 | 处理要求 | 升级路径 |
|---|---|---|
| 客户归属不明确 | 停止读取客户详情 | 客户管理岗 |
| 风险测评过期 | 不形成正式产品推荐 | 财富经理主管或合规岗 |
| 制度无现行版本 | 仅说明资料不可用，不凭经验补答 | 知识责任部门 |
| 客户或产品系统不可用 | 降级为模板或已核验信息整理 | 系统服务台 |
| 涉及投诉、欺诈或重大声誉风险 | 停止常规营销流程 | 合规、消保或风险部门 |

## 8. 留痕要求

正式业务结果至少记录任务发起人、岗位实例、客户标识、数据截止时间、制度版本、关键决策、人工确认、执行结果和下游回执。审计记录不得无必要保存完整敏感客户内容。
