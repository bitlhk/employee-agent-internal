# 信贷材料审核规则管理办法

**版本：V2.0（现行）**
**生效日期：2026-08-01**
**责任部门：授信管理部、法律合规部（演示）**

## 1. 规则分级

| 级别 | 含义 | 执行动作 |
|---|---|---|
| BLOCK | 关键条件不满足 | 停止正式审核，转人工或补件 |
| REVIEW | 存在冲突、异常或证据不足 | 允许形成草稿，必须人工复核 |
| NOTICE | 非关键提示 | 继续审核并记录说明 |

## 2. 必备规则

### R-IDENTITY-01 主体身份

申请主体身份材料缺失、失效或与申请信息不一致时，结果为 `BLOCK`。

### R-AUTH-01 授权关系

由代理人提交的案件未提供有效授权关系时，结果为 `BLOCK`。

### R-PURPOSE-01 贷款用途

贷款用途说明和核心用途证明均缺失时，结果为 `BLOCK`；材料存在但交易关系不能确认时为 `REVIEW`。

### R-PERIOD-01 材料期间

流水、收入或财务材料未覆盖业务要求期间时为 `REVIEW`，不得以行业平均或历史对话补齐。

### R-CONSISTENCY-01 关键字段一致性

主体、金额、账户、合同编号或日期存在实质冲突且无法从权威材料确认时为 `REVIEW`；疑似跨客户材料时升级为 `BLOCK`。

### R-IMAGE-01 影像质量

关键页缺失、严重模糊或字段不可识别时为 `REVIEW`；模型不得声称影像真实。

## 3. 规则生成和发布

1. AI 可以根据制度生成结构化规则草案；
2. 草案必须标记 `DRAFT` 并关联来源章节；
3. 业务专家确认适用范围、输入口径和例外条件；
4. 合规或制度责任部门批准；
5. 发布后生成不可变版本和生效时间；
6. 只有已发布且当前有效的规则可以影响正式审核 Policy。

## 4. 人工复核

命中 `BLOCK` 或 `REVIEW` 时，系统输出命中规则、材料证据、缺失信息和建议动作，不直接给出通过或拒绝结论。

## 5. 版本要求

本办法替代 V1.0。V1.0 仅用于历史追溯，不得进入当前审核任务 Context，也不得作为当前 Policy 的来源。
