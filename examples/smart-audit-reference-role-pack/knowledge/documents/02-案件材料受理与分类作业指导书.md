# 案件材料受理与分类作业指导书

**版本：V1.0**
**责任部门：授信运营部（演示）**

## 1. 适用范围

适用于贷款申请、客户尽调、用途证明、收入资产、合同凭证和补充说明等材料的首次受理与分类。

## 2. 前置检查

1. 核对当前用户和案件归属；
2. 确认本次审核的案件类型和基准时间；
3. 只读取当前任务上传或案件系统授权的文件；
4. 检查文件类型、大小、损坏状态和恶意内容扫描结果；
5. 对压缩包先执行安全解包，不运行其中程序或脚本。

## 3. 分类目录

| 一级分类 | 常见材料 | 处理重点 |
|---|---|---|
| 主体身份 | 身份证件、营业执照、授权书 | 主体名称、号码、有效期 |
| 申请信息 | 申请表、授信申请、用途说明 | 金额、期限、用途、签署日期 |
| 收入经营 | 收入证明、纳税、财务报表 | 期间、主体、口径 |
| 资金流水 | 银行流水、交易明细 | 账户、期间、交易对手 |
| 资产负债 | 房产、车辆、负债证明 | 权属、估值、余额 |
| 合同凭证 | 合同、发票、订单、收据 | 编号、金额、交易关系 |
| 其他说明 | 情况说明、补充证明 | 关联事项和责任人 |

## 4. 操作步骤

1. 生成材料内容指纹，识别重复文件；
2. 根据内容和文件属性分类，不只依赖文件名；
3. 为每份材料记录 `materialId`、文件名、类型、页数和处理状态；
4. 标记损坏、加密、低清、空白和不支持文件；
5. 输出材料目录和下一阶段建议；
6. 未读取成功的文件不得进入“已提供”清单。

## 5. 异常处理

- 文件损坏：标记“需重新上传”，不循环重试；
- 文件加密：要求通过合规渠道提供解密版本，不在对话中索要密码；
- 类型未知：进入“待人工分类”，不得强制归类；
- 内容重复：保留一份主材料并记录重复引用；
- 文件超限：说明大小限制和拆分方式。

## 6. 输出格式

```text
材料概览
已受理材料
重复或版本冲突
暂不可处理材料
需要补充的信息
下一步审核建议
```
