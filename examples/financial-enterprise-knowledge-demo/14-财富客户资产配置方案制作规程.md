# 财富客户资产配置方案制作规程（演示）

> 文件编号：LG-WM-SOP-002
> 版本：V1.0
> 归口部门：财富投顾与产品部（演示）
> 生效日期：2026-08-01
> 密级：内部
> 说明：本文为演示作业规程，不构成投资建议或真实机构制度。

## 1. 适用范围

适用于财富经理为已完成身份和风险测评核验的客户制作内部资产配置分析、客户沟通草案和候选产品清单。仅做教育说明、市场观点讨论时，可不形成正式配置方案，但仍应区分事实与判断。

## 2. 前置条件

制作正式方案前必须具备：

1. 客户属于当前财富经理授权范围；
2. 风险测评有效，且风险等级、测评日期可核验；
3. 客户资产、负债、期限、流动性需求和重大约束信息达到最小完整度；
4. 产品事实来自当前产品系统，并含状态和数据时间；
5. 所用配置方法和适当性制度为当前有效版本。

## 3. 输入信息

### 3.1 客户事实

- 可投资资产规模及数据时间；
- 现有持仓分类、比例、期限和集中度；
- 风险等级与测评有效期；
- 投资期限、现金流安排和流动性底线；
- 客户明确表达的目标、限制和偏好。

### 3.2 产品事实

- 当前在售状态；
- 产品风险等级；
- 投资期限、开放安排和最低金额；
- 当前机构、组织和渠道是否可销售；
- 费用、主要风险及产品资料更新时间。

## 4. 操作步骤

### 4.1 核验业务现场

先核验客户身份、归属、风险测评和数据时间。字段缺失时标记“待核实”，不得用同类客户经验补齐。

### 4.2 形成现状诊断

从流动性、收益目标、风险暴露、期限结构和集中度五个维度描述现状。诊断应使用区间、比例和可验证事实，不把短期市场观点写成客户长期属性。

### 4.3 形成目标配置区间

目标配置应以大类资产区间表达，并说明调整理由、前提和潜在风险。不得用虚假精确收益率、保本或必然达成目标等表述。

### 4.4 筛选候选产品

仅从产品 MCP 返回的当前可售集合中筛选。先执行风险、状态、渠道、期限和最低金额等硬性检查，再进行排序和解释。未通过硬性检查的产品不得以“仅供参考”方式混入推荐清单。

### 4.5 形成建议与备选方案

至少包含基准方案和必要的备选路径。每项建议应同时说明客户侧依据、产品侧依据、主要风险和需要客户确认的信息。

### 4.6 复核并交付

交付前执行销售合规检查清单。正式对外材料按规定进入人工复核或确认流程；内部草稿应显著标识用途。

## 5. 必查项清单

- [ ] 客户风险测评仍有效
- [ ] 客户和产品数据时间已披露
- [ ] 候选产品当前在售且渠道可用
- [ ] 产品风险等级未超过客户允许范围
- [ ] 期限、最低金额和流动性要求匹配
- [ ] 推荐理由同时引用客户事实和产品事实
- [ ] 历史业绩未被表述为未来承诺
- [ ] 被排除产品记录业务原因

## 6. 禁止项

- 不得为了凑足产品数量虚构或网页搜索产品；
- 不得用客户历史购买高风险产品推定其当前风险等级；
- 不得绕过停售、渠道或组织限制；
- 不得在客户信息不足时生成“正式建议”；
- 不得隐去重大不利信息或仅展示有利情景。

## 7. 异常处理与升级

| 情形 | 处理方式 |
|---|---|
| 风险测评过期 | 停止正式推荐，提示先完成重新测评 |
| 产品系统不可用 | 只完成持仓诊断，不给出当前产品清单 |
| 客户明确要求风险错配产品 | 说明不适配原因并升级合规处理，不执行推荐 |
| 数据来源冲突 | 标记冲突字段，向数据责任系统核验 |
| 现行制度不可用 | 不形成正式适当性结论 |

## 8. 留痕要求

保存客户数据时间、产品结果版本、配置方法版本、适当性裁决、排除原因、人工确认和最终交付版本。模型中间推理不作为正式业务留痕。
