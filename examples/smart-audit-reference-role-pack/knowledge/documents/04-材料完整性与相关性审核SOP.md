# 材料完整性与相关性审核 SOP

**版本：V1.0**
**责任部门：授信运营部（演示）**

## 1. 前置条件

- 已完成案件类型确认；
- 已取得当前有效必备材料清单；
- 已完成材料受理和关键字段提取；
- 当前规则版本和适用范围明确。

## 2. 完整性审核

按案件类型将材料分为：

| 结果 | 定义 | 后续动作 |
|---|---|---|
| 已提供 | 文件可读取且满足最低字段要求 | 进入相关性和一致性审核 |
| 缺失 | 必备材料未提供 | 判断是否阻断并生成补件项 |
| 需补正 | 已提供但过期、模糊、缺页或字段不足 | 说明具体补正要求 |
| 无法确认 | 清单或材料类型存在歧义 | 转人工确认 |
| 不适用 | 根据案件条件可排除 | 记录排除依据 |

关键材料缺失时，不得输出“材料完整”。

## 3. 相关性审核

至少检查：

1. 材料主体是否与申请主体或授权关系一致；
2. 材料期间是否覆盖审核要求；
3. 合同、发票、流水和用途说明是否指向同一交易；
4. 金额关系是否合理且币种一致；
5. 材料是否属于当前申请事项，而非其他项目或历史案件；
6. 授权书、代理关系和签署主体是否匹配。

## 4. 阻断规则

以下情况至少阻断正式审核并要求人工处理：

- 主体身份或授权关系无法确认；
- 核心申请表、用途材料或关键证明缺失；
- 当前有效必备清单不可用；
- 关键材料存在版本冲突且无法判断现行版本；
- 材料疑似属于其他客户或案件。

非关键附件缺失时可以生成有限审核草稿，但必须列出缺口。

## 5. 输出要求

```text
审核范围和规则版本
已提供材料
缺失材料
需补正材料
相关性问题
阻断项
可继续执行的审核事项
人工复核建议
```

每项问题关联 `materialId`、规则编号和安全摘要，不复制完整敏感材料。
