# 材料与证据审核 SOP

## 材料状态

先将规则与案件中的材料名称归一到同一业务类型。当文件语义、主体和期间已明确对应时，不因“最近一期财务报表”与“财务报表”之类标签差异制造缺件。只有名称指向多种不同材料、关键范围不清或无法建立对应关系时，才列为待确认。

| 状态 | 判定 | 输出方式 |
|---|---|---|
| 已提供且满足要求 | 材料可读，主体、期间和必要字段满足当前规则 | 列入可用证据 |
| 已提供但需补正 | 文件存在，但期间不足、字段缺失、模糊或与当前案件关联不清 | 说明已有范围和精确差额 |
| 未提供 | 当前材料集中不存在 | 列入缺失，说明用于证明什么 |
| 无法读取 | 文件存在，但损坏、加密、低清或格式不支持 | 不按已核验处理 |
| 不适用 | 当前业务类型或规则明确不要求 | 记录不适用依据 |

必须避免把同一份材料无解释地同时列入“已提供”和“缺失”。如果规则要求六个月流水，实际只有三个月，应说：

> 已提供近三个月流水，但不满足近六个月连续性要求；需补充前三个月并核对中间无断档。

## 证据矩阵

每个会改变审核结论的事实至少记录：

```text
审核事项
材料与字段
值或状态
归属主体
时点或覆盖期间
口径与币种
原文位置
确认状态
```

材料来源的可信程度不能脱离当前问题。银行流水可直接证明账户交易，但不能单独证明每笔入账都是经营收入；申请表可证明申报内容，但不能单独证明内容真实。

## 差异处理

1. 确认是否为同一主体和同一账户归属。
2. 确认时间期间是否重合。
3. 确认比较的是流入、收入、利润、余额还是合同金额。
4. 口径可比时才计算差额和差异率。
5. 检查材料是否已提供可合理解释的调节项。
6. 将结果标为已核验冲突、口径不可比或证据不足。

## 最小补件

补件不是资料越多越好。每项补件必须指向一个未解问题：

```text
补什么
用来证明什么
需要覆盖的期间或主体
补齐后重新执行哪项审核
```
