# 车险顾问岗位助手 1.2.5 发布记录

## 发布结论

`auto-insurance-advisor@1.2.5` 面向保险顾问岗位默认预装发布。该版本不新增平台治理层，重点提升一线业务价值：

- 从客户字段罗列升级为“触发事件、核心矛盾、关键问题、保障方向、下一步”的访前判断；
- 首轮只询问会改变产品方向或沟通策略的问题；
- 两个候选必须体现保障范围、价格或服务上的真实取舍；
- 将“只要便宜”“出了事故肯定赔”等异议转化为客户可回答的决策问题；
- 区分客户基础事实、画像派生建议、产品元数据和培训话术，减少将 Demo 文案当成当前事实的风险。

EA Runtime 继续负责权限、数据用途、产品状态和写操作边界；本 Skill 只负责保险需求判断、候选解释和客户沟通。

## 同模型对照

评测固定为 GLM-5.2、保险顾问岗位、同一客户与产品 MCP，仅替换 Skill Artifact。

| 任务 | 1.1.0 | 1.2.5 |
|---|---|---|
| 续保访前准备 | 字段和险种清单完整 | 增加核心矛盾、少而关键的问题、候选取舍与排除理由 |
| 无客户事实的产品异议 | 容易为了话术冲击力假设具体用车场景 | 先做同口径比较，再确认车辆用途、现有保障、出险和预算 |
| Demo 数据边界 | 会直接复述培训数字 | 明确区分演示元数据与正式条款，精确数字转为待核验 |
| 匿名业务 Judge | 访前题持平 | 修正专家口径后的产品异议题高置信度胜出 |

这不是“正式保险产品知识已认证”的结论。当前保险产品 MCP 仍是培训 Demo 源；生产销售前必须替换为当前有效的产品条款、报价和核保数据。
