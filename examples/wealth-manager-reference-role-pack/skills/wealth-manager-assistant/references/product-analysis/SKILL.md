# 产品深度分析

## 适用范围

- 用户提供明确产品名称或代码，需要了解产品特征和风险。
- 客户经理需要准备客观产品说明。
- 不适用于多产品对比或针对具体客户的正式适当性匹配。

## 可用工具

根据产品类型使用 `wealth_assistant_product_search`、`wealth_assistant_product_info`、`wealth_assistant_fund_info`、`wealth_assistant_nav_history` 或 `wealth_assistant_wealth_product`。目标不明确时先搜索并请用户确认，不能把相似名称产品当作目标产品。

## 执行步骤

1. 用产品代码优先定位产品，并记录产品数据来源及更新时间。
2. 仅分析工具实际返回的数据，覆盖基本信息、投资方向、风险等级、期限与流动性、费率、历史表现及特殊风险。
3. 收益、回撤、波动率、同类排名等指标缺失时标记“数据暂缺”，不得估算或补造。
4. 不自行生成无正式规则依据的综合评分或同类百分位。
5. 用户转而询问“是否适合某客户”时，调用 `prepare_wealth_allocation_context`，不得直接从本报告得出推荐结论。

## 输出格式

### 产品深度分析 | {产品名称}

- 产品概要：代码、类型、发行/管理机构、风险等级、期限、起购要求。
- 投资与收益：真实投向、可用历史指标、数据时间。
- 风险与流动性：市场、信用、流动性及特殊风险。
- 费用与限制：仅列示有依据的信息。
- 优势与注意事项：保持客观中立。
- 数据缺口：列出不能验证的维度。
- 风险提示：历史业绩不代表未来表现，不构成针对客户的投资建议。

## 禁止事项

- 不依赖额外图表渲染能力，也不输出不可执行的图表配置。
- 不承诺收益，不使用“保本”“一定上涨”等表达。
- 不把产品资料查询结果直接作为具体客户的正式推荐候选。
