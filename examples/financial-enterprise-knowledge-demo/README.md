# 企业与金融岗位知识库演示资料

> 版本：2026.07-demo.2
> 性质：除明确标注的监管原文外，其余内容均为虚构的产品演示资料，不代表任何真实企业制度，也不构成法律、投资或合规意见。

这套资料用于验证岗位智能体对企业公共制度、岗位操作规范和官方监管原文的分层检索、跨文档归纳和来源引用能力。住宿金额、审批层级、时限、系统名称及内部分级均为演示口径。

## 知识库划分

- 企业公共知识：01、02、03、05、06、09、10，所有岗位均可检索。
- 财富经理岗位知识：04、08、11，仅 `wealth-manager` 岗位可检索。
- 风控经理岗位知识：05、06、07、09、10，仅 `post-loan-risk-control` 岗位可检索。
- 审核专员岗位知识：03、05、06、09、10，仅 `credential-compliance` 岗位可检索。
- 保险顾问岗位知识：04、05、06、09，仅 `insurance-advisor` 岗位可检索。
- 投顾分析岗位知识：06、08、09，仅 `investment-researcher` 岗位可检索。

`SOURCES.md` 仅用于记录演示资料来源和免责声明，不导入运行时知识索引。

## 建议测试问题

- 普通员工去上海出差三晚，酒店每晚上限是多少？
- 临时买了公务机票但没有事前审批，还能报销吗？
- 电子发票打印后，原始电子文件还需要保留吗？
- C2 客户能否购买 R4 产品？客户坚持购买怎么办？
- 客户身份证照片能否发到个人邮箱，让供应商代为处理？
- 客户交易行为异常时，能否告诉客户已经提交可疑交易报告？
- 贷款客户连续两期现金流下降，应该触发什么级别的预警？
- 群聊中的债券报价可以直接转发给客户吗？
- 员工买入限制名单证券前需要做什么？

回答应同时区分“公开监管原则”和“本演示库内部规则”，并显示实际引用文件。
