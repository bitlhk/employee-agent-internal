# 访前诊断与需求发现 SOP

## 目标

把授权客户事实转换成一次有目标的客户会面，而不是换一种格式复述 CRM。

## 判断流程

### 1. 建立事实快照

按数据来源和时间整理当前任务真正需要的信息：

- 客户身份和授权范围；
- 家庭或经营背景中与本次任务有关的部分；
- 风险测评状态及有效时间；
- 资产、负债、持仓、到期事件和已知现金需求；
- 历史沟通中已确认的目标、承诺和未决事项；
- 当前适用制度与数据缺口。

不要为了让材料显得完整而展示全部客户字段。没有参与本次判断的信息不进入主材料。

### 2. 找到变化与触发事件

访前材料必须回答“为什么是现在”。常见触发包括：

- 产品即将到期；
- 风险测评即将到期或客户情况发生变化；
- 资产规模、收入、家庭责任或流动性需求变化；
- 持仓集中度或账面损失变化；
- 上次会面遗留事项需要推进。

没有明确触发事件时，将“确认本次客户目标”作为首要任务，不自行制造销售机会。

### 3. 区分四类信息

| 类型 | 判定                   | 输出方式               |
| ---- | ---------------------- | ---------------------- |
| 事实 | 当前来源直接支持       | 陈述事实并标注时点     |
| 假设 | 由事实合理推导但未确认 | 使用“需要确认”“可能”   |
| 缺失 | 会改变方案但当前没有   | 转成关键问题           |
| 冲突 | 来源、时点或口径不一致 | 暂停相关结论并要求核验 |

禁止把“可能支付设备款”写成“企业资金紧张”，也不要把客户等级直接解释为真实波动感受。

### 4. 识别核心矛盾

优先寻找一项最影响本次决策的矛盾：

- 表面诉求与资金用途；
- 收益目标与风险金额感受；
- 长期目标与短期负债；
- 客户主张与历史事实；
- 单一资产信心与家庭风险集中；
- 当前购买意愿与适当性条件。

如果无法基于事实说明矛盾，就不要为了“有洞察”强行推断。

### 5. 选择首轮关键问题

从所有缺口中选最多三个信息增益最高的问题。排序标准：

1. 回答后是否可能改变能否推荐；
2. 是否可能改变流动性或期限约束；
3. 是否可能改变客户可承受的损失金额；
4. 是否能区分两个明显不同的后续方案。

高质量问题示例：

- 这笔资金最早可能在什么时间、因为什么用途被使用？
- 如果组合短期下降 3%，对应金额是多少，客户会等待、减仓还是立即退出？
- 当前目标中，流动性、资本保全和长期增值哪个必须优先保证？

低质量问题示例：

- 您最近怎么样？
- 您希望收益高一点还是低一点？
- 您对投资有什么想法？

客户回答后，可以围绕新出现的关键事实继续追问，不受首轮三个问题限制。

### 6. 定义面谈目标

面谈目标描述本次要确认什么、推进到哪一步，而不是预设销售结果。

推荐格式：

```text
本次触发：为什么现在需要沟通
本次目标：确认 2-3 项会改变决策的信息
成功标准：会后能够形成什么判断或下一步
不在本次处理：需要其他岗位、制度或数据支持的事项
```

## 访前输出模板

访前简报的“已核验事实”至少明确写出以下五项；没有数据时写明缺失，不能直接省略：

- 客户事实的数据时间；
- 风险测评当前状态及有效时间；
- 持仓和到期事项的已知情况或数据缺口；
- 当前适用制度的名称或版本；
- 会改变后续判断的待核实事项。

```text
客户当前重点

已核验事实
- 事实、来源、数据时间

核心矛盾
- 表面诉求
- 可能冲突
- 为什么会影响决策

待验证假设
- 假设及依据

首轮关键问题
1. ...
2. ...
3. ...

面向财富经理输出时，明确使用“首轮关键问题”或“谈话要点”作为标题，保证问题可以直接带入面谈。

本次面谈目标
- ...

风险与边界
- 当前可以讨论什么
- 当前不能形成什么结论

会后推进
- 动作、责任人、前置条件
```

## 自检

- 是否只是复述客户资料，而没有指出变化和矛盾？
- 是否把模型假设写成了客户事实？
- 三个问题是否真的可能改变后续决策？
- 是否预设了某个产品或成交结论？
- 是否包含可以在会后验证的推进目标？
