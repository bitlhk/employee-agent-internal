# 保险销售合规红线与检查清单（演示）

> 文件编号：LG-IA-CHK-001
> 版本：V1.0
> 归口部门：合规管理部、消费者权益保护部（演示）
> 生效日期：2026-08-11
> 密级：内部

## 1. 适用范围

用于保险顾问在产品解释、话术建议、客户沟通和销售陪练前进行检查。该清单是作业工具，不代替业务系统、核保、理赔或确定性 Governance Policy。

## 2. A 类：客户和权限

- [ ] 客户属于当前用户授权范围
- [ ] 当前任务只使用最小必要客户字段
- [ ] 客户和车辆事实来自授权业务系统
- [ ] 客户敏感信息未进入公共知识或无关日志

## 3. B 类：车辆和如实告知

- [ ] 车辆类型和使用性质已核实或标记待核实
- [ ] 营运、新能源、高里程等重要场景未被忽略
- [ ] 未建议客户隐瞒出险记录或重要事实
- [ ] 无法核实的信息未写成确定事实

## 4. C 类：产品和报价

- [ ] 产品来自当前产品 MCP
- [ ] 产品版本和数据时间可定位
- [ ] 没有将示范产品表述为真实在售产品
- [ ] 没有在缺少报价源时生成具体保费
- [ ] 保障、限制和免责采用一致口径

## 5. D 类：销售表达

- [ ] 未承诺最低价、必然承保或必然赔付
- [ ] 未虚构优惠、活动、返现或内部政策
- [ ] 未贬低同业或编造竞品缺陷
- [ ] 未使用“什么都保”“肯定能赔”等误导表达
- [ ] 客户明确拒绝时停止营销

## 6. E 类：动作和升级

- [ ] 报价、投保、核保、理赔进入正式系统
- [ ] 投诉进入消保流程
- [ ] 客户数据外发使用批准通道
- [ ] 写操作具备确认、幂等和审计
- [ ] 技术依赖不可用时没有补造业务结果

## 7. 硬性停止条件

出现以下任一情形时停止当前正式业务结论：

- 客户归属失败；
- 车辆使用性质和重要事实存在冲突；
- 产品数据来源不明或详情不可用；
- 用户要求隐瞒重要事实；
- 用户要求虚假价格、优惠、承保或赔付承诺；
- 投诉、核保或理赔超出当前岗位边界；
- Governance 或身份服务不可用。

## 8. 业务可读提示

拒绝时说明原因和下一步，例如：

```text
暂不能形成正式产品建议。
原因：车辆当前使用性质尚未确认，可能影响产品适用范围和承保条件。
下一步：请先在正式业务系统核实车辆用途，再继续匹配。
```

## 9. 留痕要求

记录检查时间、执行人、未通过项、处理结果、规则版本和必要输入指纹。不得在审计事件中保存完整客户对话或身份证件信息。
