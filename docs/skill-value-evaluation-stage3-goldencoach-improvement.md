# Skill 价值评测第三阶段：销售陪练 Skill 改进闭环

验证时间：2026-09-04

## 阶段目标

第二阶段证明了六个重点 Skill 均具备真实 A/B 评测条件，同时发现
`goldencoach-stage-evaluation@2.2.0` 在短对话阶段点评任务中反而弱于无
Skill：它把聚焦任务扩展成完整七模块评分，并从有限证据推断客户画像。

第三阶段不增加治理引擎，而是用该负向结果牵引 Skill 的专业能力改进，
再用相同模型、相同问题和相同 Runtime 证明新版本是否真正更好。

## 2.2.1 改进内容

- 将聚焦阶段点评设为默认模式；只有用户明确要求完整复盘、七模块评分或总分时才进入完整训练评估。
- 将对话事实、教练判断和待核实项分开，禁止从一次短对话推断金融素养、风险偏好、性格、收入或资产层级。
- 阶段点评优先识别一个关键销售断点，输出最多两个亮点、两个缺口和三个高信息增益问题。
- 车险续保问题优先核实实际用车变化、现有保障基线，以及保费顾虑来自同保障涨价还是保障升级取舍。
- 保留完整训练评分和 LSCPA 异议分析，但仅在任务明确需要时按需加载。

## 结论边界

本阶段证明的不是“增加规则后更合规”，而是评测机制能够发现 Skill 的真实专业缺陷，并牵引新版本在任务理解、证据边界、问题质量和一线可用性上稳定提升。

当前 Judge 属于 AI 专业评审，结果可以作为版本发布和回归证据，但不标记为独立人类专家 Ground Truth。后续若获得真实教练或保险销售专家复核，可在不改变冻结输入的前提下补充人类校准标签。
