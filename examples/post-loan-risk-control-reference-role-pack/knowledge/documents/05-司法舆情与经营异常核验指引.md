# 司法舆情与经营异常核验指引

**版本：V1.0**
**责任部门：风险监测部、法律合规部（演示）**

## 1. 数据分类

| 类型 | 可信等级 | 使用要求 |
|---|---|---|
| 法院执行、失信、监管处罚 | 权威事实 | 记录案号/文号、日期和来源 |
| 工商经营异常、税务异常 | 权威或准权威事实 | 核对主体和更新时间 |
| 新闻报道 | 辅助信息 | 交叉验证，不单独定性 |
| 社交媒体和未署名消息 | 线索 | 不得作为风险事实 |

## 2. 核验步骤

1. 以统一信用代码核对主体，避免同名误判；
2. 合并同一事件的重复记录；
3. 区分立案、审理、判决和执行阶段；
4. 记录事件发生日期和数据更新时间；
5. 判断事件与偿债能力、经营持续性或核心资产的关联；
6. 重大事件提交人工复核。

## 3. 舆情边界

负面舆情只能形成核验任务。没有权威事实或第二来源支持时，不得直接触发红色预警，不得在正式报告中使用确定性措辞。

## 4. 输出

输出已核验事实、待核验线索、重复合并说明、业务关联和升级建议。无数据不等于无风险，应说明数据覆盖范围。
