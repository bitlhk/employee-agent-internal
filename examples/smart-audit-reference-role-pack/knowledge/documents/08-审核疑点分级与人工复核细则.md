# 审核疑点分级与人工复核细则

**版本：V1.0**
**责任部门：授信管理部、法律合规部（演示）**

## 1. 疑点等级

| 等级 | 定义 | 系统动作 |
|---|---|---|
| L1 提示 | 非关键字段缺失或轻微格式问题 | 记录提示，可继续审核 |
| L2 补件 | 材料不足但可通过补充恢复 | 生成补件清单 |
| L3 复核 | 关键字段冲突、规则歧义或异常线索 | 强制人工复核，不给最终结论 |
| L4 阻断 | 身份/授权无法确认、跨客户材料或关键规则缺失 | 阻断正式审核并升级负责人 |

## 2. 必须转人工的情形

- 关键主体、金额、账户、合同编号存在无法解释的冲突；
- 影像模糊、遮挡、缺页或疑似篡改，但系统没有可靠验证能力；
- 当前有效规则不存在、版本冲突或适用范围不明；
- 用户请求最终通过、拒绝、例外批准或授信决定；
- 命中高风险规则，需要业务判断或外部核验；
- 系统无法确认材料属于当前客户或案件；
- 外部识别服务返回互相矛盾的结果。

## 3. 人工复核任务内容

```text
案件引用
疑点等级
命中规则及版本
材料与字段引用
已完成检查
无法自动确认的原因
建议复核动作
期望完成时间
```

不得把完整证件号、账号或原始影像复制到任务标题和通知消息中。

## 4. 权限与确认

创建复核任务前必须：

1. 确认当前用户有权访问案件；
2. 展示拟创建任务的安全摘要；
3. 获得用户明确确认；
4. 生成幂等键；
5. 执行时重新校验当前权限；
6. 保存业务回执。

用户在任务执行期间获得更多权限，不得扩大当前任务范围；权限被撤销时必须拒绝写入。

## 5. 关闭条件

复核任务只能由有权人员关闭。关闭时记录结论、补充材料、规则版本、处理人和时间，不修改原始 Context Receipt。
