# 产品横向对比

## 输入与定位

1. 要求用户提供 2-4 个产品，产品代码优先。
2. 使用只读产品工具逐一定位；名称存在多个匹配时先让用户确认。
3. 无法验证的产品不得进入对比，也不得补造产品参数。

## 对比方法

1. 使用尽可能一致的数据时间口径，并逐项标注来源和更新时间。
2. 对比产品基本信息、风险等级、期限、流动性、投资方向、费率、可用历史表现和限制条件。
3. 只比较参与产品均有依据的字段；缺失项显示“数据暂缺”。
4. 不用固定权重或模型主观评分替代正式企业规则。
5. 产品差异结论使用客观措辞，不贬低任一产品。

## 客户适配边界

纯产品资料对比可以使用原始只读产品工具。用户要求“哪个更适合某位客户”时：

1. 确认客户稳定标识并调用 `get_governed_customer_profile`。
2. 调用 `prepare_wealth_allocation_context`。
3. 只对 `eligibleProducts` 提供客户适配说明。
4. `excludedProducts` 只能解释排除原因，不得推荐。

## 输出格式

### 产品对比 | {产品 A} / {产品 B} / ...

| 维度 | 产品 A | 产品 B | 数据口径/缺口 |
|---|---|---|---|
| 风险等级 | | | |
| 期限与流动性 | | | |
| 投资方向 | | | |
| 费率 | | | |
| 历史表现 | | | |
| 限制条件 | | | |

随后说明核心差异、适用场景和风险提示。历史业绩必须注明不代表未来表现。

## 禁止事项

- 不依赖额外图表渲染能力，不输出无数据支持的雷达图或评分。
- 不承诺任何产品收益，不替客户作最终决定。
- 不因名称相似合并不同产品。
