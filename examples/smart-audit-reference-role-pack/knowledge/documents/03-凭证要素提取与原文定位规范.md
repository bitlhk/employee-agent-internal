# 凭证要素提取与原文定位规范

**版本：V1.0**
**责任部门：运营管理部、数据管理部（演示）**

## 1. 目标

将业务凭证中的关键字段转换为结构化结果，同时保留字段来源和确认状态，使审核人员能够回到原材料复核。

## 2. 字段输出要求

每个字段至少包含：

```text
fieldName
value
sourceMaterialId
pageOrRegion
extractionStatus
```

`extractionStatus` 仅允许：

- `CONFIRMED`：材料清晰且字段可直接读取；
- `NEEDS_REVIEW`：存在遮挡、低清、多个候选值或语义歧义；
- `NOT_FOUND`：材料中未找到；
- `NOT_APPLICABLE`：该材料类型不适用。

## 3. 常用字段口径

| 字段 | 口径 |
|---|---|
| 主体名称 | 保留材料原文，同时生成标准化候选值 |
| 证件/统一代码 | 展示时脱敏，比较时使用受控标准化值 |
| 金额 | 分离数值和币种，不默认人民币 |
| 日期 | 保留原文并转换标准日期；无法判断时不补年月日 |
| 合同/发票编号 | 保留前导零、字母和分隔符 |
| 账户 | 默认只展示后四位 |
| 交易对手 | 保留原文，不自动合并同名主体 |

## 4. 原文定位

- PDF 和文档记录页码及文本片段；
- 图片记录区域坐标或可复核的位置描述；
- 表格记录工作表、行列或单元格；
- 无法稳定定位时标记 `NEEDS_REVIEW`，不得伪造坐标。

## 5. 质量边界

- 只有文本内容时不得声称核验印章、签名、照片或版式；
- OCR 低置信结果不得自动覆盖用户或权威系统字段；
- 多份材料出现不同值时全部保留，交由一致性审核处理；
- 不从常见模板、历史对话或模型知识补造缺失字段；
- 提取提示词和字段 Schema 变更必须版本化。

## 6. 复核清单

- 字段是否来自当前案件材料；
- 金额和币种是否分离；
- 日期是否保留原文；
- 敏感字段是否脱敏；
- 每个关键字段是否可定位；
- 不确定字段是否明确标记。
