# 车险异议处理与回访操作指引（演示）

> 文件编号：LG-IA-GDE-002
> 版本：V1.0
> 归口部门：车险客户经营部、培训发展部（演示）
> 生效日期：2026-08-11
> 密级：内部

## 1. 适用范围

用于车险外呼、面谈和续保回访中的异议识别、话术建议和下一步安排。正式报价、优惠审批和投诉处理不属于本指引。

## 2. 处理原则

1. 先准确复述客户关切；
2. 用客户原话作为意图判断证据；
3. 只引用当前产品和正式系统可核验事实；
4. 提供选择，不施压、不贬低同业；
5. 客户明确拒绝时尊重选择；
6. 投诉、正式报价和复杂业务转人工。

## 3. 常见异议

### 3.1 价格偏高

先确认比较口径是否一致，再解释保障范围、免赔、服务和车辆风险差异。没有正式报价时不得给出具体降价承诺。

### 3.2 对比其他公司

引导客户核对保障责任、限额、免责、服务和报价条件。不得贬低同业或虚构对方产品缺陷。

### 3.3 需要考虑

询问客户最关心的一个问题，提供简短资料和合理回访时间。客户不愿继续时结束营销，不连续追问。

### 3.4 没有时间

尊重客户时间，确认是否需要预约。不得用虚假时限、库存或优惠制造紧迫感。

### 3.5 不愿提供信息

解释信息用途和最小必要范围。客户拒绝提供关键承保信息时，不形成正式报价或匹配结论。

## 4. 标准输出

```text
客户意图
判断证据
建议话术
风险提醒
下一步动作
```

## 5. 回访安排

回访计划应包含客户标识、沟通主题、计划时间、责任人和待核实事项。当前没有 CRM 写能力时只生成内部草稿，不得表述为“已创建任务”。

## 6. 必查项

- [ ] 已引用客户真实表达
- [ ] 话术与当前异议一致
- [ ] 产品和价格事实可核验
- [ ] 未贬低同业或虚构优惠
- [ ] 未诱导客户隐瞒重要事实
- [ ] 客户明确拒绝时停止营销
- [ ] 投诉和越界事项已转人工

## 7. 禁止项

- 不得承诺最低价、返现或未经批准的优惠；
- 不得以虚假活动结束时间制造紧迫感；
- 不得隐瞒免赔、免责和承保限制；
- 不得建议修改或隐瞒车辆用途；
- 不得阻止客户投诉或要求删除真实负面反馈；
- 不得自动向个人微信或私人邮箱发送客户资料。

## 8. 异常处理

| 情形 | 处理 |
|---|---|
| 客户明确投诉 | 停止营销，记录事实并转消保流程 |
| 客户要求人工 | 说明转接事项并转人工 |
| 报价或优惠问题 | 转正式报价和审批系统 |
| 涉及核保、理赔 | 转核保或理赔专岗 |
| 对话信息不足 | 先追问，不强行归类 |
