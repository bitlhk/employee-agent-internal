# 灵感金融 · 投顾分析岗位标杆任务矩阵 V1.0

## 1. 文档定位

本矩阵定义 `investment-researcher` 岗位的六项可复用任务合同。它不是固定股票 Demo，也不新增运行时配置；股票、基金、指数、债券、公告、新闻和宏观事实均由当前授权 Wind MCP 动态返回。

## 2. 岗位边界

投顾分析负责公开授权金融数据的研究、比较、风险核验和研究材料整理，不负责：

- 获取或推断客户账户、持仓和适当性信息；
- 代替财富经理完成客户产品推荐；
- 直接下单、调仓或承诺收益；
- 把模型记忆、网页片段或无日期数据写成当前市场事实；
- 以研究意见替代有权人员的投资决策和合规审核。

## 3. Golden Task Matrix

| ID | 任务 | 业务目的 | 主要能力 | 核心验收 |
|---|---|---|---|---|
| IR-GT-01 | 公司快速研究 | 建立公司、业务和关键变量基础认知 | Wind 股票档案、财务、行情；研究 Skill | 对象唯一、事实有日期、结论与事实分离 |
| IR-GT-02 | 最新财报复盘 | 识别盈利质量、现金流和预期差 | 财务数据、公告、财报分析 Skill | 期间明确、同比可比、缺失不补写 |
| IR-GT-03 | 公司与同业比较 | 形成口径一致的横向比较 | 股票/指数数据、同业比较 Skill | 同期间同口径、缺失值不计零、比较可解释 |
| IR-GT-04 | 估值与风险核验 | 评估估值位置和关键风险 | 行情估值、风险指标、估值 Skill | 数据新鲜、估值口径明确、不输出伪精确目标价 |
| IR-GT-05 | 公告与事件影响 | 区分事实、影响路径和待验证项 | 公告新闻、宏观行业数据、事件 Skill | 原始公告优先、新闻不替代公告、影响标记推断 |
| IR-GT-06 | 研究备忘与跟踪 | 沉淀结论、证据、失效条件和跟踪动作 | 研究备忘 Skill、确认写入 Demo 跟踪任务 | 先草稿后确认、幂等、业务回执、无交易执行 |

## 4. 数据可信顺序

```text
监管/交易所/公司正式公告
        ↓
Wind 结构化行情与财务数据
        ↓
Wind 新闻与宏观行业数据
        ↓
岗位 Reference Knowledge
        ↓
模型分析与推断
```

动态数据至少保留：`sourceSystem`、证券代码、数据期间或 `asOf`、字段口径和结果指纹。来源、期间或对象不完整时，不得形成正式研究结论。

## 5. 确定性治理

### INVESTMENT_RESEARCH_DATA_ASSURANCE

核验研究对象、来源、数据时间、关键维度和可比性。关键事实缺失时只允许输出事实摘要和补数清单。

### INVESTMENT_RESEARCH_OUTPUT_BOUNDARY

禁止自动交易、收益承诺和无客户适当性上下文的个性化产品建议；允许内部研究观点、风险清单和跟踪任务草稿。

## 6. Readiness

| 状态 | 允许 | 禁止 |
|---|---|---|
| READY | 完整研究草稿、比较、估值与跟踪建议 | 自动交易、收益承诺 |
| DEGRADED | 已核验事实、方法框架、补数清单 | 当前行情结论、伪精确估值 |
| BLOCKED | 最小输入清单和恢复建议 | 正式研究意见和写操作 |

## 7. Evidence

- Context Receipt：证明本次提供了哪些 Wind 数据、岗位知识和能力；
- Response Evidence：绑定最终回答实际引用的数据和知识；
- Business Receipt：仅在确认后创建隔离 Demo 研究跟踪任务；
- 不在 Receipt 中复制完整公告正文、报价语料或敏感机构信息。

## 8. Reference / Enterprise Binding

灵感提供任务模板、研究 SOP、数据门禁、Skill 路由和 Eval。企业部署时映射自己的研究制度、数据授权、观察池、研究审批和留痕系统，不要求重写原文，也不把 Reference 观点当作企业投研结论。
