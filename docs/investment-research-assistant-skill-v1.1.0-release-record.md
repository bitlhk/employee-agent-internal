# 投顾分析岗位助手 1.1.0 发布记录

## 发布结论

`investment-research-assistant@1.1.0` 作为投顾分析岗位默认预装主技能发布。它不替代现有选股、财报、估值、公告和债券专项技能，而是为投顾任务提供统一的研究主线：

```text
研究问题
-> 待验证假设
-> 最少充分证据
-> 盈利与定价驱动
-> 反证、催化剂和失效条件
-> 可执行跟踪项
```

本次重点提升研究智力，不新增投顾治理引擎。EA Runtime 继续负责工具授权、来源可用性、数据时效和写操作确认；Skill 负责研究问题、证据组织、财务解释和研究表达。

## 主要变化

- 公司研究从百科式资料罗列改为盈利驱动、市场预期、反证和失效条件；
- 财报复盘要求利润表、现金流量表和资产负债表交叉验证；
- 经营现金流改善必须结合合同负债、应收、存货和营运资金解释；
- 估值先选择适用口径，再讨论高低，不给伪精确目标价；
- 公告解读采用“公告事实、影响变量、反映时间、未确认条件”影响链；
- 默认输出一页决策型简报，并给出两到四个可观察跟踪项；
- 增加任务型取数纪律，避免为了填满报告重复查询。

## 同模型真实对照

评测固定为 GLM-5.2、投顾分析岗位和同一组 Wind 工具，只比较无目标 Skill 与 `1.1.0` Artifact。执行经真实 EA Runtime，Promptfoo 负责批次执行和输出采集，原生 `skill_tool` 证明确实加载了目标版本。

| 任务 | 无目标 Skill | 1.1.0 |
|---|---|---|
| 贵州茅台一页公司研究 | `3/3/3/2` | `4/4/4/4` |
| 最新财务数据质量复盘 | `3/2/3/2` | `4/4/4/4` |

评分顺序为：专业匹配、业务完整性、结构表达、可执行性。两题均由 GLM-5.2 匿名业务 Judge 高置信度选择 `1.1.0`。

### 公司研究提升

无 Skill 输出以行情、估值和技术指标罗列为主；`1.1.0` 将结论收敛为“提价对冲量减”，解释提价、非标减量和直营占比对收入及毛利率的传导，并给出批价、收入增速、毛利率等跟踪阈值和失效条件。

### 财报复盘提升

第一次候选运行只分析利润和现金流，未完整取得资产负债表，因此输给无 Skill。根据评测反馈补齐三表交叉验证后重跑，`1.1.0` 能结合合同负债、存货、应收和现金流基数解释盈利质量，不再将现金流改善直接推断为渠道打款积极，最终四项均为 4 分。

这条“发现缺口 -> 修改 Skill -> 同题回归”的链路，是本次技能评测牵引质量提升的核心证据。
