# 流水、财务与偿债审核 SOP

## 一、先判断可比性

比较任何两个金额前先确认：

- 主体一致，或已有可核验的账户授权、关联关系；
- 期间重合，或已有可复算的同期调整；
- 口径一致，例如税前/税后、含税/不含税、流入/营业收入、月均/期间合计；
- 币种和换算时点一致。

任一条不成立时，先输出“不可直接比较”及原因。可以展示表面差额，但不得把它定性为收入造假或重大冲突。

## 二、流水质量分析

在材料支持时，按以下顺序分析：

1. **账户归属**：账户名与申请主体是否一致，不一致时是否有授权或关联关系证明。
2. **覆盖期间**：是否达到当前规则要求，中间是否存在断档。
3. **入账构成**：区分经营回款、关联方往来、借款流入、内部调拨和偶发大额。没有交易明细或对手信息时不猜测分类。
4. **稳定性**：看频次、波动、季节性和客户集中度，不只看总流入。
5. **现金结余**：分析经营净现金、期末余额与拟还款安排的关系，不把流入总额等同于可还款资金。

## 三、收入与财务交叉验证

将申报值、流水可支持值、财务报表值和其他独立证据放在同一张表中，但保留各自口径。

口径可比时：

```text
绝对差额 = 申报值 - 可核验值
相对差异 = |绝对差额| / 申报值
```

例如申报 80 万元、可核验值 35 万元，表面差额为 45 万元，占申报值 56.25%。`80 / 35 - 1 = 128.57%` 表示申报值比可核验值高出的比例，不得在未标注分母时把它混称为相对差异率。

如果当前规则没有差异阈值，只报告数值和影响，不自行创造“超过 20% 即高风险”之类规则。

## 四、用途与还款来源

- 申请金额与合同、订单、预算不一致时，计算差额并查找差额用途说明；
- 区分第一还款来源、辅助还款来源和抵质押缓释手段，不把担保物等同于经营还款能力；
- 偿债比率、月供和现金覆盖率必须使用当前规则指定的口径和确定性计算结果；
- 缺利率、期限、还款方式或稳定收入时，明确列出无法计算的参数。

## 五、审核意见

使用“问题 - 证据 - 影响 - 动作”结构：

```text
问题：对公流水账户名与申请主体不一致。
证据：申请主体 A；流水账户名 B；当前未见授权或关联证明。
影响：该流水暂不能用于证明 A 的经营回款和还款来源。
动作：补充账户归属、授权或关联关系证明，然后重新执行流水分析。
```

材料完整且无关键冲突时，不应为了显得审慎而制造阻断。可以形成工作意见草稿；当前范围内没有剩余问题时明确写“无”，不主动扩展到偿债能力、交易真实性或其他未被要求的下一阶段审核。
