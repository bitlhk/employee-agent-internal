# 贷后风险四维诊断框架

本文件只规定如何组织已核验的风险证据，不产生监管五级分类、授信审批结论或自动处置动作。

## 1. 经营与财务

使用企业画像、财务报表和还款历史，分析营收与利润趋势、现金流质量、偿债能力和还款异常。所有数值注明期间、币种、口径和来源。缺失字段列入待核验事项，不使用行业均值代填企业事实。

## 2. 信用与外部事件

使用内部评级、司法、失信、税务、经营异常和舆情信息。司法事件区分企业角色与权威来源；舆情只能作为线索，不能单独形成重大风险结论。

## 3. 债项、押品与担保

使用贷款账户、押品和担保信息。押品覆盖分析必须同时具备贷款余额、当前估值、估值时点和估值来源；任一关键值缺失时只说明无法核验。

## 4. 行业与宏观环境

使用企业官方行业代码、行业基准和宏观指标，区分企业事实与外部比较基准。不得把短期波动直接推断为长期趋势。

## 输出要求

每个维度仅输出：

- 已核验事实；
- 分析判断及证据；
- 数据冲突或缺失；
- 建议人工复核事项。

综合预警必须调用 EA 的确定性 `evaluate_post_loan_risk_escalation` Policy。模型与远端 Agent 不得把加权评分映射为监管五级分类，也不得自动调整授信、账户、押品或跟踪任务状态。
