# 财富客户沟通与业务推进模式

## 目标

把专业判断转成财富经理可以直接使用的自然表达。重点是提出判断、验证假设、解释取舍和形成下一步，不是背诵营销模板。

## 基本结构

```text
从客户当前事件切入
→ 说明为什么先讨论目标和约束
→ 提出一个关键判断
→ 用问题验证判断
→ 比较可选路径和取舍
→ 说明风险与不确定性
→ 确认下一步
```

## 1. 提出判断但不替客户下结论

推荐表达：

> 我现在更关注的不是先选哪款产品，而是这笔资金最早什么时候会用。这个时间会直接决定我们能承担多长期限。

避免：

> 您最适合稳健产品，我已经替您选好了。

判断要能追溯到客户事实，同时保留客户确认空间。

## 2. 验证假设而不冒犯客户

推荐表达：

> 我看到这笔资金近期可能有经营用途，但目前时间还没有确认。这个理解是否准确？

避免：

> 您企业最近资金很紧张吧？

先说明依据，再邀请客户确认；不要把模型推断包装成已知事实。

## 3. 把百分比风险转换成金额感受

在有确定资产金额时，可以帮助客户理解风险：

> 问卷等级说明了适当性范围，但真实感受可能不同。如果这部分资产短期下降 3%，对应金额会让您等待，还是立即调整？

没有确定金额时，不自行估算损失金额。

## 4. 解释为什么暂时不能正式推荐

使用业务语言说明缺少什么以及为什么重要：

> 目前客户目标和风险测评已经确认，但在售产品数据还没有完成核验。现在可以先确定配置约束，具体产品需要等当前可售清单恢复后再给出。

不要向业务用户堆叠工具名、接口错误、状态码或内部执行步骤。

## 5. 比较 A/B 方案

先说共同底线，再说差异：

> 两套方案都先保留已经确认的流动性需求。A 更重视短期稳定，B 使用更多长期不用的资金承担波动。差别不是哪个一定更好，而是您愿意用多少波动换取长期增值机会。

避免把 B 描述成“收益更高的升级版”，也不通过暗示客户损失机会来推动选择。

## 6. 处理常见异议

### “收益太低”

> 如果只看收益，这个方案确实不突出。需要一起看的是，这部分资金承担的是近期使用、稳定底仓还是长期增值。先确认任务，再比较相同任务下的产品。

### “怕错过行情”

> 一次投入可能完整参与上涨，也会一次承担下跌。我们先确认哪些资金即使波动也不会影响计划，再决定是否分阶段，而不是用市场预测替代资金规划。

### “只要回本就卖”

> 买入价格会影响感受，但今天是否继续持有，仍要看产品逻辑、当前风险、资金用途和替代选择。先把三种路径的条件和成本列清楚，再决定。

### “风险等级允许，为什么不能多配”

> 风险等级说明可购买范围，不等于建议配置上限。还要结合期限、流动性、持仓集中度以及您对具体金额波动的感受。

## 7. 处理服务不满

先让客户完整表达，再区分市场损失、产品变化、历史沟通和服务缺失。可以承认服务体验，不在证据不全时推卸责任或承认法律责任。

推荐表达：

> 今天先不带新产品。我想把购买时的判断、风险沟通、产品变化和您现在的资金需求分别复盘清楚，再讨论继续持有、调整或退出各自需要满足什么条件。

客户明确指控误导销售、适当性问题或提出处理诉求时，按 Runtime 和机构流程升级处理，不把投诉当成普通营销异议。

## 8. 形成下一步

下一步必须具体、可执行且不强迫：

```text
动作：补充未来 12 个月资金用途表
责任人：客户提供，财富经理整理
前置条件：确认设备款金额和最早支付时间
时间：下次方案讨论前
```

不要使用“抓紧购买”“最后机会”等压力表达。产品销售窗口确需说明时，只陈述经核验的客观时间，不制造稀缺感。

## 话术自检

- 是否像真实财富经理，而不是制度或系统通知？
- 是否先解释客户问题，再介绍产品？
- 是否存在未经事实支持的个性化判断？
- 是否把客户自主决定写成形式化免责声明，而实际仍在强推？
- 是否给出了明确下一步，而不是以“您看怎么样”结束？
