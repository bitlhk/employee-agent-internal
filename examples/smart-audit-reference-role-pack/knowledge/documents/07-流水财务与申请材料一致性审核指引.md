# 流水财务与申请材料一致性审核指引

**版本：V1.0**
**责任部门：授信运营部、风险管理部（演示）**

## 1. 目标

对申请表、银行流水、收入证明、财务报表、合同和用途材料进行跨材料核对，识别需要进一步核验的冲突和异常线索。

异常线索不是欺诈结论，也不替代贷后风险分级。

## 2. 数据准备

- 明确各材料主体、账户、期间、币种和数据来源；
- 统一日期和金额格式，但保留原值；
- 标记缺失月份、缺页、重复交易和无法识别字段；
- 记录计算口径和是否包含内部转账、冲正或一次性事项。

## 3. 一致性检查

| 维度 | 检查内容 | 常见疑点 |
|---|---|---|
| 主体 | 申请人、账户持有人、合同主体 | 主体不一致或授权不明 |
| 金额 | 申请金额、合同金额、发票和流水 | 金额差异无法解释 |
| 时间 | 申请、合同、发票、付款日期 | 交易发生在合同前或期间不覆盖 |
| 用途 | 申请用途、合同标的、收款方 | 用途和交易关系不一致 |
| 收入 | 收入证明、流水入账、财务收入 | 周期、来源或规模差异明显 |
| 负债 | 申请披露、流水还款、征信/证明 | 存在未披露还款线索 |

## 4. 异常线索

- 短期集中大额入账后快速转出；
- 高频整数交易或重复同额交易；
- 主要交易对手与用途材料无明显关系；
- 个人与企业账户频繁混用；
- 财务收入与主要账户流入长期偏离；
- 材料之间出现相同编号但不同金额或主体；
- 关键交易集中在材料截止日前后。

命中线索后必须回到具体交易和材料核验，不得只输出模式名称。

## 5. 降级规则

- 流水期间不完整：只分析已覆盖期间并列出缺口；
- 缺少币种：不合并金额；
- 缺少交易对手：不推断用途；
- 财务口径不一致：分别展示，不直接计算趋势；
- 数据量过大：说明抽样或聚合范围，不声称完成全量审核。

## 6. 输出格式

```text
已核验事实
一致项
冲突项
异常线索及材料位置
使用的计算口径
数据缺口
人工复核建议
```
