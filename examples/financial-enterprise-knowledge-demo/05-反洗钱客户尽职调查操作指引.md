# 反洗钱客户尽职调查操作指引（演示）

## 1. 何时开展尽职调查

与客户建立业务关系、办理达到内部触发条件的一次性业务、客户身份资料存疑、交易行为与客户画像明显不符或有合理理由怀疑涉及洗钱风险时，应开展或重新开展客户尽职调查。

## 2. 调查内容

1. 识别并核实客户身份；机构客户还应识别受益所有人、控制关系和授权经办人。
2. 了解建立业务关系和交易的目的、预期规模、资金来源和资金用途。
3. 对高风险客户实施强化尽调，包括补充资产或收入证明、核实交易背景、提高复核层级和持续监测频率。
4. 对低风险且法规允许的情形可采用简化措施，但不得免除身份识别和持续监测。
5. 身份不明、拒绝提供必要材料或提供明显虚假信息的，不得建立业务关系或继续办理相关业务。

## 3. 内部风险信号

- 短期内交易规模与职业、收入或历史行为明显不匹配。
- 多个无明显关系账户向同一账户集中转入后快速转出。
- 频繁变更受益人、联系方式、开户地址或授权经办人且无法合理解释。
- 刻意规避内部审核、拆分交易或要求员工不要记录真实用途。
- 涉及高风险国家或地区、制裁名单、负面信息或复杂不透明控制结构。

风险信号不等于违法结论。员工只记录事实、证据和合理疑点，由反洗钱专岗按照制度分析和处理。

## 4. 保密要求

客户身份资料、交易信息、尽调结论、调查线索和可疑交易报告属于严格受控信息。不得向客户或无关人员透露“已上报、拟上报或正在调查可疑交易”，不得在普通群聊、个人邮箱或个人设备中保存。

## 5. 升级流程

一线人员发现风险信号后，当日提交反洗钱线索；主管在 1 个工作日内完成完整性复核；反洗钱专岗决定补充调查、持续监测、限制服务、拒绝办理或按规定报告。紧急制裁命中或涉嫌资金快速转移时立即电话升级，不等待普通工单。

本指引不设置法定大额或可疑交易金额阈值，实际阈值应由持牌机构依据现行监管规则和系统参数维护。
